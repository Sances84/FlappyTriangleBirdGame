# Flappy Triangle Bird Game
After a month of development, i decided to upload my personal game project called Flappy Triangle Bird Game.

It is a clone to the famous 2014 game Flappy Bird.

**Disclaimer: Source code of this game is AI generated unless otherwise specified with commentary inside game code.**

Also, it is GPL3 licensed so as of upload. Free to use under some conditions written in this license.

Pull requests and issues are welcome in to contribute to the game.

The game is possible to port into other OS using own makefile into it.

Please do pull requests if you want to give the repository have some ports of game into other devices.

# History of development of game
October 27, 2026 - start of development, planning to make a platformer genre videogame, but i decided workaround to just make flappy bird game clone easier than the platformer, and this is how in commit history was written "Platformer" name of project.

I used Viktor Shitov's russian book called "C++ for beginners" to develop it, so this is why IDE software that i use is Dev C++ following by this book.

AI GPT-Luna series helped to migrate it in SDL, forced after at October 30, 2026 when i initialized repository of the game then to record history in.
